# Тесты по русскому языку · 5–11 классы

Интерактивные тесты к урокам недели 31.08–06.09.2026 — **«Учительская» / Арина Галицкая**.

**Онлайн:** https://prouchitelskaya.github.io/russian-tests-31-08-06-09-2026/

## Что внутри

Одна страница — семь блоков тестов, по одному на класс. В каждом классе **20 вопросов** с мгновенной проверкой и объяснением каждого ответа.

| Класс | Тема |
|---|---|
| 5 | Разделительные ь и ъ |
| 6 | Фонетика. Орфоэпия. Графика |
| 7 | Морфология: существительное, прилагательное, числительное |
| 8 | Правописание сложных слов |
| 9 | Сочинение 13.3: подготовка и критерии |
| 10 | Изобразительно-выразительные средства |
| 11 | Орфоэпия. Орфоэпические нормы |

Прямые ссылки на класс: `…/#g5`, `…/#g6`, … `…/#g11`.

## Технически

- Статический сайт: HTML + CSS + vanilla JS, без сборки и зависимостей.
- `data.js` — банк вопросов (JSON). Авторская конвенция: правильный ответ всегда `options[0]`, `answer: 0`; на странице варианты перемешиваются.
- Прогресс (лучший результат по классу) хранится в `localStorage` (`rustests20260824:v1`).
- Светлая/тёмная тема — по `prefers-color-scheme`.
